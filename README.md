# ai-help-desk-bot

**Live demo:** https://ai-app-desk-bot.streamlit.app

AI-powered IT triage using Groq (Llama 3.3) + RAG with ChromaDB — 
pulls live KB from Confluence, classifies incidents, generates 
troubleshooting steps, auto-creates ServiceNow incidents with 
assignment group routing, deployed on Streamlit Community Cloud.

To run download the repo and run streamlit run app.py if you want too.
